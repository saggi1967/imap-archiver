# mailarc 2.0.0.0

Dieses Release bringt **mailarc auf den Mac** – als fertiges Installationspaket –
und macht die Volltextsuche präziser.

## 🍏 Native macOS-Distribution

mailarc lässt sich jetzt als klassisches macOS-Paket ausliefern:

- **`.dmg`** mit professionellem, automatisch erzeugtem Hintergrund und
  Volume-Icon → einfach öffnen und das `.pkg` doppelklicken.
- **`.pkg`-Installer** mit Begrüßung, Lizenz und Abschlussseite. Installiert
  `mailarc` nach `/usr/local/mailarc` und legt einen Symlink unter
  `/usr/local/bin/mailarc` an.
- **Eigenständig** dank eingebettetem Python (PyInstaller) – auf dem Zielrechner
  muss weder Python noch eine Abhängigkeit vorinstalliert sein.

Selbst bauen:

```bash
brew install create-dmg
packaging/macos/build.sh
# → dist/macos/mailarc-2.0.0.0.pkg  und  .dmg
```

Nach der Installation:

```bash
mailarc --version
```

## 🔎 Exakte Phrasensuche

Mehrteilige Suchbegriffe wie Belegnummern (`26/130`) wurden bisher in einzelne
Tokens zerlegt und per ODER gesucht. Neu:

```bash
mailarc search query "26/130" --phrase   # bzw. -x
mailarc search count "26/130" -x
```

Mit `--phrase`/`-x` müssen die Tokens **direkt aufeinanderfolgen** – deutlich
treffsicherer für Nummern, Codes und feste Wortgruppen.

## ⚠️ Hinweis zur Signierung

Die erzeugten `.pkg`/`.dmg` sind **unsigniert**. Für die Weitergabe außerhalb des
eigenen Rechners sollten sie signiert (`productsign`/`codesign`) und notarisiert
(`notarytool`) werden, sonst blockt Gatekeeper die Installation.
